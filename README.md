<h1 align="center">Website DimTech Serviços de TI</h1>

Este é o repositório oficial do [dimtech.com.br](https://dimtech.com.br/), meu website profissional e portfólio para serviços de suporte e manutenção de TI.

O site é uma **página estática (Static Site)** construída do zero, focada em ser leve, responsiva e informativa. Ele serve como meu cartão de visitas digital, detalhando os serviços que ofereço (como formatação, backup, clonagem de HD/SSD) e apresentando artigos e tutoriais para ajudar os usuários.

## 🚀 Site no Ar (Live Demo)

Você pode acessar o site completo em produção no seguinte link:

**➡️ [https://dimtech.com.br/](https://dimtech.com.br/)** 

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído puramente com tecnologias front-end, sem a necessidade de um back-end ou banco de dados, garantindo velocidade máxima de carregamento.

* **HTML5:** Estruturação semântica de todas as páginas.
* **CSS3:** Estilização customizada, utilizando `flexbox` e `grid` para layouts modernos.
* **Design Responsivo:** O arquivo `css/responsivo.css` garante que o site se adapte perfeitamente a desktops, tablets e celulares.
* **JavaScript (ES6+):** Para interatividade e manipulação do DOM.
* **jQuery:** Utilizado para simplificar scripts e integrar bibliotecas de plugins.
* **Slick Carousel:** Biblioteca (ver `slick.js`) usada para os *banners* rotativos na página inicial e galerias.
* **Lity:** Biblioteca (ver `lity.min.js`) usada como um *lightbox* (popup) leve para visualização de imagens.
* **WOW.js:** Biblioteca (ver `wow.min.js`) usada para revelar animações conforme o usuário rola a página.

## 📂 Estrutura do Projeto

A estrutura é organizada por funcionalidade:

* **`/` (Raiz):** Contém todas as páginas HTML principais (`index.html`, `servicos.html`, `sobre.html`, `contato.html`, etc.).
* **`css/`:** Contém todas as folhas de estilo, incluindo o `reset.css`, o `estilo.css` principal, o `responsivo.css` e os estilos dos plugins (ex: `slick.css`).
* **`js/`:** Contém os scripts JavaScript, incluindo as bibliotecas (jQuery, Slick, Lity, WOW) e os scripts customizados (`animacoes.js`).
* **`img/`:** Contém todos os ativos visuais, organizados por tipo (Banners, Ícones, imagens de tutoriais como `Macrium`, etc.).
* **`CNAME`:** Arquivo de configuração do GitHub Pages para apontar para o domínio `dimtech.com.br`.

## 📜 Páginas e Funcionalidades

O site é composto por diversas páginas estáticas que detalham os serviços oferecidos:

* **Home (`index.html`):** Página principal com banners e chamadas para ação.
* **Serviços (`servicos.html`):** Um hub que leva para páginas detalhadas, como:
    * `formatacao.html`
    * `backup.html`
    * `clonagem.html`
    * `trocaparassd.html`
* **Conteúdo (`artigos.html`, `tutorias.html`):** Uma seção de blog com guias (ex: `ventoy.html`, `backupwindows.html`).
* **Sobre (`sobre.html`):** Apresentação profissional.
* **Contato (`contato.html`):** Formulário de contato (requer um serviço externo de e-mail ou back-end para funcionar).
